# 📝 체험단/기자단 가이드 자동 생성 모듈 개발 명세서

## 1. 프로젝트 개요
* **목적:** 마케팅 실무자가 캠페인별 필수 정보만 입력하면, 블로거 배포용 '체험단/기자단 가이드라인' 텍스트가 즉시 생성되는 웹 모듈.
* **개발 방식:** 외부 API 연동 없이 프론트엔드(HTML/CSS/Vanilla JS)의 템플릿 치환(Template Literals) 방식 활용.

## 2. 화면 UI/UX 구성
화면은 크게 좌측 '입력 폼'과 우측 '결과 출력' 영역으로 나뉩니다. 깔끔하고 모던한 UI로 구성해 주세요.

**A. 입력 폼 영역 (Input Form)**
* `브랜드 키워드` (필수, text)
* `주요 키워드` (필수, text)
* `서브 키워드` (필수, text)
* `해시태그` (필수, text, 쉼표로 구분)
* `예시 이미지` (선택, file) - 가이드용 레퍼런스 이미지 첨부
* `버튼`: "🚀 가이드라인 생성하기" (클릭 시 우측 영역에 결과 렌더링)

**B. 결과 출력 영역 (Output Result)**
* `결과 텍스트 박스`: 줄바꿈과 포맷이 유지되도록 출력 (`white-space: pre-wrap` 적용). 첨부된 이미지가 있다면 지정된 위치에 미리보기 렌더링.
* `버튼`: "📋 클립보드에 복사하기" (원클릭 전체 텍스트 복사, Clipboard API 활용)

## 3. 핵심 텍스트 템플릿 로직 (JavaScript)
사용자 입력값을 아래 텍스트의 해당 위치에 치환하여 출력합니다.

**📌 전반적인 가이드**

(01) 브랜드 키워드 : [브랜드 키워드]
(02) 주요 키워드 : [주요 키워드]
(03) 서브 키워드 : [서브 키워드]
(04) 글자 수 : 700자 ~ 1700자 이내
(05) 사진 수 : 10 ~ 20장 이내

**📸 사진 가이드**

[촬영 방법]
(01) 쪽지로 보내드린 예시 화면을 그대로 캡처하지 마시고, 서비스 소개서나 웹페이지의 다양한 화면을 컴퓨터, 휴대폰 화면으로 연 상태에서 촬영한 파일을 업로드 부탁드립니다.
(02) 원고 내에 사진들을 한 각도로(한 배경으로) 찍는 게 아닌 다양한 각도의 다른 배경으로 찍어서 작성 부탁드립니다.
[※ 첨부된 예시 이미지가 있다면 이곳에 렌더링]

[첨부 및 배치 규칙]
(01) 사진 수 : 10 ~ 20장 이내로 첨부 부탁드립니다.
(02) 사진 활용 : [사진 1장] - [글 10줄 이내] - [사진 1장] - [글 10줄 이내] 의 형식으로 작성해주세요.
  → 사진 1장 당 사진 아래에 최소 글 4줄 ~ 5줄을 꼭 지켜주세요!
(03) 사진이 3장 이상 모여있거나 연속되지 않게, 글은 10줄 이상 넘지 않도록 작성해주세요.

**✒️ 내용 작성 가이드**

[참고 자료]
(01) 보내드린 서비스 소개서 및 링크를 확인하여 작성하실 내용을 참고해주세요.

[키워드 작성 규칙]
(01) 원고에 주요 키워드 '[주요 키워드]'은(는) 7번 이내로 작성해주세요.
(02) 다음 중 한 가지 키워드를 선택하고 해당 키워드는 7번 이내로 작성해주세요.
  → [서브 키워드]
(03) 선택한 키워드를 제외한 다른 키워드는 3번 이상 중복하여 사용하지 말아주세요.
(04) 원고에 '[브랜드 키워드]'(은)는 1번 이내로 작성 부탁드립니다. (최대한 사진을 통한 간접 노출을 부탁드립니다.)

[원고 작성 방향]
(01) 다른 홈페이지, 커뮤니티, 기사 정보성 글을 그대로 복사해서 작성하지 마시고 정보성 글을 사용하게 된다면 글을 쓰는 방식을 많이 우회해서 작성 부탁드립니다.
(02) 히든 이미지 사용 불가한 점 양해 부탁드립니다.
(03) 원고 내에 [브랜드 키워드]의 특장점 혹은 선택한 이유 등을 숫자를 붙여 작성해 자연스럽게 숫자가 들어가게 해주세요.
  → 예) 브랜드 성공을 위한 첫걸음, [브랜드 키워드]를 선택한 이유
  1.~~
  2.~~
  3.~~
(04) 경험성 동사, 주체, 시간표현, 긍정적인 표현(좋음)을 사용하여 글을 작성해주세요.
  → 예) 최근에 브랜드 리뉴얼을 준비하면서 [브랜드 키워드]과 함께했는데, 방향성이 명확해지고 결과도 좋아서 정말 잘한 선택이었다고 생각해요!

[제목 및 마무리 규칙]
(01) 제목에 필수 키워드('[브랜드 키워드]')를 자연스럽게 맨 앞 또는 중간에 배치해주시고, 제목이 동사/질문 형태로 끝나지 않게 부탁드립니다. ('[브랜드 키워드]' 키워드를 제목 내 필수로 넣어주세요)
  → 틀린 예시) "[브랜드 키워드]로 [주요 키워드]을 시작한다면?"
  → 맞는 예시) "[브랜드 키워드] [주요 키워드] 솔루션으로 만드는 매출 중심의 시장 진입 전략"
(02) 맞춤법 검사기를 사용하여 검수하시고 업로드 해주시기 바랍니다.
(03) 좋아요와 블로그 스크랩을 열어놔 주세요.
(04) 블로그 최하단에 아래의 키워드를 순서대로 태그해주세요.
  → 블로그 글 하단에는 키워드 태그하지 말아주세요.
  [해시태그]
(05) 글 최하단에 쪽지로 전달드린 서비스 링크를 첨부해주세요.
  [여기에 서비스 링크를 삽입해주세요]

**🚨 추가 안내**

(01) 가이드라인이 지켜지지 않을 시 수정 요청이 있을 수 있습니다.
(02) 협의 없이 캠페인 취소가 불가합니다.
(03) 작성하신 게시글은 6개월 이상 유지해주세요.

## 4. 예외 처리
* 필수 텍스트 값이 비어있을 경우 "모든 필수 항목을 입력해 주세요" Alert 노출.
